Section I: Bezier Curves and Surfaces

Part 1: Bezier curves with 1D de Casteljau subdivision

What is de Casteljau's Algorithm:

De Casteljau's algorithm is a recursive method used to evaluate a point on a Bezier curve for a given parameter t ∈ [0, 1]. Given n control points, we perform n−1 linear interpolations between adjacent points to create a new set of n−1 intermediate points. For any two adjacent control points pi and pi+1, the intermediate point p'i is calculated as:p'i = (1 − t)pi + tpi+1 We repeat this process recursively until only a single point remains, which gives the point on the Bezier curve at parameter t.

How We Implemented de Casteljau's Algorithm:

We implemented the logic within the evaluateStep function. Using a for loop to traverse the input vector points, we perform iterative linear interpolation. For each pair of adjacent points pi and pi+1, we applied the Lerp formula using the class member variable this->t as the interpolation parameter and calculated the intermediate point using the formula above. Each newly computed point was then added to the result vector using push_back(). When key E is pressed, this function is called repeatedly and the program reduces the number of points by 1 on each step until a single point remains, which is then used by viewer to render the Bezier curve.

Part 2: Bezier surfaces with separable 1D de Casteljau

How does de Casteljau's Algorithm extends to Bezier Surface:

The de Casteljau alogrithm extends to Bezier surfaces by applying the same 1D interpolation algorithm across 2 dimensions. A Bezier patch is an n x n grid of control points and 2 parameters, u and v. To evaluate a point on the surface, we first treat each row of n control points as independent Bezier curves and evaluate it at parameter u. This will reduce the grid to a single column of n new points. This resulting column is then treated as a final Bezier curve and evaluated at parameter v. The final point produced will lie on the Bezier surface at (u, v).
